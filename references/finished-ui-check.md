# 成品自检：新建和改版共同执行

每次完成视觉实现后，用当前获准的浏览器检查成品本身，不需要旧版。局部修改覆盖受影响组件；新页面、公共样式或全局改版覆盖不同布局及相关组件。文档修改不启动业务页面。

## 执行闭环

1. **列状态。** 根据实际页面列出代表页面与状态：常态、长内容、菜单展开、消息出现与消失、弹窗打开与关闭，以及相关窄窗口。没有的组件不新增；不要仅检查首页。
2. **真实操作。** 打开页面，从用户入口进入并触发组件。每个状态等待对应可观察条件，短暂反馈在消失前检查；不要等所有状态都结束才截一张首页。
3. **检测并看图。** 检查局部几何、可见性与焦点，保存并实际查看该状态截图。滚动检查首屏外内容。控制台零错误、页面无横滚不代表局部布局正常。
4. **修复并复测。** 对确定的重叠、错位、裁切、异常折行、丢失提示和不可达操作先修复，再重复原操作及相关状态。公共规则改变后复查使用它的代表组件，旧截图不能代表修复后结果。
5. **据结果交付。** 每个计划状态记录通过、失败或未执行，机械检查与目视检查分开。未测、浏览器失败或看不到截图时不能填通过；无法继续修复则说明阻塞与剩余缺陷。

## 看什么、操作什么

| 对象 | 检查要点 |
|---|---|
| 页面、表格、表单、卡片 | 标题、数值、长标签和操作不重叠、不裁切、不逐字挤压；没有意外局部滚动条；分组清楚；按钮可达 |
| Toast / 临时反馈 | 触发后容器完整，图标、文案、关闭按钮排列正常，不散落覆盖导航；按产品约定自动消失或手动关闭，关闭后不残留遮挡和焦点入口 |
| 菜单 | 从入口展开，定位正确，边缘不被裁切，选项可达；选择、取消和外部关闭符合实际设计 |
| 模态 | 焦点进入，Tab/Shift+Tab 不落入背景；检查关闭、焦点返回和可访问名称；非模态不强制锁焦点 |
| 加载、空态、错误、告警 | 用本地模拟或安全测试输入触发已有状态，确认内容可见、错误可恢复、状态替换后无残留；不触发真实业务写入 |
| 窄窗口与放大 | 检查目标窗口及发生重排的断点附近；实际切换模块、进入子页，不能仅证明侧栏缩小或页面没横滚 |

具体焦点和布局检查也见 [细节审查](detail-audit.md)。改版额外做 [前后比较](redesign-checks.md)，它不能替代本节。

## 可选工具：在当前页面记录检查

`scripts/ui-self-check.js` 无依赖，可通过当前浏览器的页面求值功能注入文件内容。它不启动浏览器、不点击、不改业务数据；先按页面实际 DOM 配置选择器，再通过浏览器正常操作。

```js
// 在页面上下文执行；选择器是示例，须替换成实际组件。
window.uiCheck = createUISelfCheck(['message-open', 'message-closed']);
// 用浏览器点击真实入口、等待消息出现，然后：
uiCheck.inspect('message-open', [
  { type: 'visible', selector: '#notice' },
  { type: 'contained', selector: '#notice .message', container: '#notice' },
  { type: 'contained', selector: '#notice .close', container: '#notice' }
]);
// 保存并实际查看截图后，按观察填写；不能机械复制为通过。
uiCheck.review('message-open', {
  status: 'passed', evidence: '/absolute/path/message-open.png',
  note: '容器、文字和关闭按钮完整，无重叠，未遮挡主要操作'
});
// 等产品约定的消失条件，或点击关闭，再检查：
uiCheck.inspect('message-closed', [{ type: 'hidden', selector: '#notice' }]);
// 同样截图并填写关闭后的 review；缺失则报告 not-run。
uiCheck.report(); // 导出 JSON，保留状态、结果和截图引用。
```

支持 `visible`、`hidden`、`contained`、`focusWithin`。选择器必须唯一；错误选择器或多匹配会失败。`visible` 只检查样式、尺寸与视口相交，不能证明无遮挡或未被祖先裁切；`contained` 只比较子项与容器矩形，不能证明排版美观；滚动区内有意超出需按设计单独检查。`hidden` 接受移除或布局/visibility 隐藏，不把仅透明或移到屏幕外当作可靠关闭。

工具不会自动理解任意项目结构、验证截图内容或替模型修代码。`review` 是执行者看图后的记录；不能用它伪造证据。重跑 `inspect` 会清除该状态旧的视觉结论；重新加载页面需重新注入与执行。计划中未执行的状态和未看图的状态保持 `not-run`，不能变成绿色通过。
